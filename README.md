## 2. Дизайн и эргономика системы

1. **Лендинг:**
   - Тёмный обсидиановый фон (`#08090B`), строгая типографика с отрицательным трекингом (`-0.035em`).
   - 3D-перспективный мокап тёмного терминала управления с вкладками цехов, статусами слесарей и живым протоколом проверки Gemini Vision.
   - Минималистичный Bento Grid без эмодзи (только точные векторные SVG-иконки).
   - Плавные анимации на GSAP.

2. **Веб-панель мастера смены:**
   - Светлая эргономичная палитра (`#F4F6F9`), скругленные плашки с радиусом 28px, разметка в 3 колонки:
     - **Левая колонка:** Навигационный рельс («НарядAI»), кнопки переключения разделов смены (Главная, Оборудование, Наряды, Бригада, Настройки), блок быстрого создания наряда (&lt;1 мин, &le;6 нажатий).
     - **Центральная колонка:** Заголовок «Здравствуйте, Ерлан Сатпаев», 3 плашки метрик (Выполнено `18 +8 нарядов`, Отработано `31ч -6ч`, Эффективность `93% +12%`), плавный двухлинейный график динамики смены, таблица текущих нарядов со статусными точками.
     - **Правая колонка:** Карточка сотрудника (Ербол Ахметов @akhmetov_e, бригадир слесарей) с кнопками вызова рации и видеоинспекции, лента событий с прикрепленным актом дефектовки и окно отправки сообщений с микрофоном.

3. **Мобильное приложение исполнителя (Flutter):**
   - Интуитивный чистый интерфейс (фон `#F2F2F7`, белые групповые карточки).
   - Крупные сенсорные кнопки высотой **56-64 px** под рабочие перчатки.
   - Полный цикл 10 статусов (Принять, В очередь, Отклонить, В работе, Приостановить, Закрыть с фото и ТМЦ).
   - Полноценная локализация на казахский и русский языки.

## 3. Сценарий живой защиты (Раздел 11 регламента)

Интерактивный раннер на вкладке **«Демо-сценарий (7 мин)»** позволяет в один клик пройти все 9 шагов регламента:

1. **Шаг 1:** Мастер открывает панель смены: статусы персонала, доска канбан.
2. **Шаг 2:** Создание аварийного наряда по фото течи масла насоса 1ГрТ. ИИ автоматически рекомендует свободного слесаря Ахметова Е. (5 разряд, рейтинг 96%).
3. **Шаг 3:** Push со звуком на телефон рабочего → «Принять» → «Начать исполнение» (статус у мастера меняется моментально).
4. **Шаг 4:** Второй наряд с коротким дедлайном ставится в очередь → истекает срок → ИИ отправляет оповещение о просрочке мастеру и рабочему.
5. **Шаг 5:** Слесарь закрывает первый наряд: описание работ, шифр Г-03, материалы, обязательное фото «После».
6. **Шаг 6:** ИИ проверяет наряд, сверяет фото «до/после», выставляет оценку 5/5 (96 баллов).
7. **Шаг 7:** Третий наряд закрывается без фото и с завышенным расходом масла → ИИ ставит вердикт «Требует доработки» и объясняет причину.
8. **Шаг 8:** Формирование сводки смены и расчет рейтинга исполнителей.
9. **Шаг 9:** Аналитика на истории за 3 месяца - демонстрация заложенных аномалий конвейера К-3 и перерасхода масла И-40А.
